# ☠️ Entombed by AdoLovesChicken
**A Gravestone (tomb) mod with support for Sable**

### Features:
- Safe placement
- Support for when gamerule KeepInventory is on
- Places items back exactly where they were

### Compatibility with other mods:
- Compatibility with [Sable](https://modrinth.com/mod/sable) and [Create Aeronautics](https://modrinth.com/mod/create-aeronautics) (tombs in the end can become part of the end sea)
- Migration from [HenkelMax's GraveStone Mod](https://modrinth.com/mod/gravestone-mod) and [Leclowndu93150's Gravestone x Curios API Compat](https://modrinth.com/mod/gravestone-x-curios-api-compat)
- Support for [Jade](https://modrinth.com/mod/jade), custom tooltips showing owner
- Support for [Curios](https://modrinth.com/mod/curios)

### Installation
You can either:
- Download prebuilt .jar files of the mod on [Modrinth](https://modrinth.com/mod/entombed) or in the [releases page](https://github.com/AdoLovesChicken/Entombed/releases)
- Build yourself:
```
# Clone the repo
git clone https://github.com/AdoLovesChicken/Entombed.git

# Navigate to directory
cd Entombed

# Build
./gradlew build
```
